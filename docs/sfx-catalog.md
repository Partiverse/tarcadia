# 桃花源（Tarcadia）音效全集清单 v0.1

> 版本 v0.1 · 2026-10-03 · 上游：`audio-brief.md`（三层架构/15 曲/验收 A/B/梦层梯度）、`presentation-ux.md` §1（天气集）、`chusi-numbers.md`（除祟动作）、`gathering-almanac.md`（物候接口）、`narrative-mainline.md`（现代性声轨=叙事立场）。用途：**外包报价单+交付验收单**——本文每条都是要交文件的行。
> 交付制式统一：48kHz/24bit；loop 件 45–60 秒无痕循环并交分 stem；one-shot 交 3 变体防重复听感；全实录+foley，**采样包罐头音与 AI 生成音一律不验收**（art-style 禁则同款，写入合同）。

## 3. B 组 · 天气声（八天气 × 材质分面）

- 雨面四材质：**瓦/阔叶(芭蕉樟)/塘面/土**——绵雨(春)轻瓦+塘、雷骤(夏)阔叶砸打、连雨(秋)土墙渗滴；同引擎层=audio-brief §2 分质感口径的声音侧执行。
- 晴=村基线床（禽畜+风+人声远层）；多云=风层柔化 diff；霜=清晨收缩+踩霜脆响；雾=**声距压缩**（混音规程：远景声高频滚降+3dB 近层——听觉上的"看不见山"）；雪=近无声+压枝+踩雪咯吱；雷=首雷事件/远雷/谷响三档。
- 天气切换过渡各 1 件（8 秒内自然渐入，禁"音效开始下雨"式开关感——世界在响，不是 UI 在响）。

## 5. D 组 · UI 音（三源规程的落地件，presentation-ux §5 已锁"只许木鱼/磬/翻纸"）

| 事件 | 音 | 说明 |
|---|---|---|
| 选中/确认 | 木鱼轻点/实点 | 两档力度 |
| 打开面板 | 磬单击（余音 ≤1.5s） | 全游戏仅磬=一次 |
| 杂记/书信 | 翻纸×3 变体+合册 | 第 12 封信字模敲击=**纸声不是键声** |
| 历法环换段 | 木机括一声（算盘珠落单颗） | 每 5 天一响——日历的心跳 |
| 除夕倒计时 | 大磬→村远处爆竹地气（G 组借） | 环满一刻=人声不是音效 |
| 存档"安置" | 灯芯声（火息一线） | 已锁文案的声版 |
| 退出"灯熄了" | 同一灯芯+木栓 | 两声之间留 200ms——像人吹灯后拔门闩 |
| 信到（朱砂） | 纸+磬双声 | 朱砂语义的听觉绑定 |

## 6. E 组 · 人声当乐器（无词原则）

**全游戏无配音（已锁）；人声只作曲体声料，且一律无词或方言虚词**——绕开配音、绕开"文本方言"的语音化风险、绕开多语言本地化黑洞。

- 货郎叫卖 ×4（四季各一调，实录艺人，只取旋律轮廓可加词处理：处理为远近声像，不进入对话系统）
- 闲话嗡嗡（gossip 池的声壳：非语义人声群，事件=好感/传话发生的听觉通知）×2 密度档
- 号子（薅草/车水/打夯三件——田间 buff 事件的声前件）
- 社火喧天（人声+锣鼓混场，除祟/节日共用）
- 童谣一句（熄灯序尾声从某扇窗飘进——全游戏唯一"可辨词"人声，歌词走文本方言决议=文本层同步出现）

## 7. F 组 · 除祟（chusi-numbers 的声轨）

- 傩鼓节拍源声 ×3（3/5 连击拍床=时机窗玩法音源，与火候同一判定音设计语言）；拍板；无腔吟（深梦层，audio-brief 梦层梯度的执行件）；土鼓；筑两首（中梦层）
- 影物纸形：簌动/展开/退散（**退散=折纸收拢声，不是死亡音**——§1②"不可杀"的声音纪律）
- 烛火：护烛倒计时=火苗被风扑的摇曳声（40 秒件的渐强设计）；熄灭一线烟
- 水荡：葫芦拍水序列、苇旗插定、灯笼纸振风
- "了结"完成音=磬（复用 D 组——除祟的胜利不新增音效，**安顿的声音和打开一扇门是同一个**）
