# 桃花源（Tarcadia）人物设计语言 v0.1

> 版本 v0.1 · 2026-10-02 · 上游：`vertical-slice-design.md` §6（宗族网）、`quest-scene-style.md`（三态/请托语法）、`production-scope.md` §7（18 人账）、`art-style-guide.md` §4（剪影规格）。用途：NPC 从"功能位"变成"人"的宪法；文案交稿必过 §11 检查清单。

---

## 1. 三条最高原则

1. **每人有一处与身份不协调的角落。** 族长守着一本烧了半角的族谱；磨豆腐的婶留着镇上裁缝铺的收据（三年前的）。不协调处=人物的"隙"，是私事件与"隙"事件的发生器。没有不协调处的角色卡打回。
2. **欲望要具体到能画出来。** 禁"她善良""他想守村"式的主题描述；写"小满想看镇图书馆那扇她够不着的窗""阿松想把爹的木骡子改成能载她的自行车"。具体欲望是任务、台词、演出三处的同源素材。
3. **NPC 不是内容发放机。** 恋爱候选首先是"有自己的麻烦的人"：她的个人弧解决的问题必须与玩家无关（玩家只是搭了把手）。检验：把玩家从她的弧里删掉，故事还成立吗——必须成立。

## 2. 人物卡模板（量产 18 人 + 切片 6 人统一用）

| 字段 | 说明 | 例（黄婶） |
|---|---|---|
| 明面身份 | 村里人人知道的一面 | 寡妇，磨豆腐，族中辈分居中 |
| 不协调角落 | 唯一、具体、可视觉化 | 石磨下垫着丈夫的半块墨斗（木匠遗物，与豆腐坊无关） |
| 欲望 | 能画出来的具体物 | 把小满送出去读书，代价是自己不敢老 |
| 怕 | 欲望的阴影面 | 怕村里人夸"一个女人拉扯大不容易" |
| 语言指纹 | 句式/口头禅/禁忌词（§4） | "看你方便"挂嘴边；绝口不提"当家的" |
| 持有的知识 | 能作为关系回报的独占内容 | 霉豆腐方（好感 40）、腌期看天象（好感 20） |
| 关系边 | 至少 2 条，注明方向与温度 | 小满（依恋+控制）；黄老爷子（敬而怵）；江客（同病相怜，暗线） |
| 隙事件 | 恰 1 个，绑定不协调角落 | 夜里磨坊：玩家撞见她对着墨斗发呆，选择问/不问 |
| 日程锚 | 早/午/晚/集/雨 五档落位（§5） | 磨坊/溪边/堂屋/晒谷场帮厨/雨=休磨 |

## 3. 关系网络语法

- **边有方向与温度**：辈分边（上敬下慈，称呼锁句式）、姻亲边（热/冷两种状态可切换）、恩怨边——**每村恰 2 对恩怨**是设计资产：恩怨是调解任务、闲话池、年集座位表的永久素材源。
  - 切片实例：黄婶×黄老爷子（小满婚事旧怨）；江客×栗树坡猎户（药田与猎场界争，量产第 7 人起用）。
- **面子账**：每人有"被人说"的软指标（不显示数值，由闲话池内容体现）：夸/叹/啧/避四种口吻。玩家行为经 gossip 传播改变口吻——**做得好没人知道才是人情叙事的假**，故请托完成后赶集日会有人当面提起（复用闲话池，零额外文案成本）。
- **传话机制**：告诉 A 的秘密 3 天内 60% 概率到 B（B 由关系图谱的"话路"决定——谁跟谁嘴碎是图谱上的显式边）。玩家学会"选谁说"=中式人情的高级玩法；情报有保质期，**传话系统同时是任务失败态的温柔出口**（黄了的请托可经话路重开）。

## 4. 语言指纹（对话验收的硬标准）

- 18 人每人一份：句式长度、语气词（嘞/哩/罢了/么）、称呼习惯（按辈分表见 §6）、一条绝不说的话（禁忌词）。
- **盲读验收**：遮住名字，从个人弧台词里抽 10 句，设计者外成员辨认 ≥7/10 为合格；不足则重写该人，不动别人。
- 方言=词汇层点缀（切片决议）：词汇表随人物下发，**每人的点缀词 ≤3 个且互不重复**——全村都在"嘞"=等于没有。

## 5. 作息与生态（时间感的人物侧）

- 切片 3 档日程（早/午/晚）保留为灰盒底线；量产升 5 档：+赶集 +雨/节气异态。
- 规则：**入夜即眠**（约 22 点后全村灯次熄，熄灯顺序=人物性格演出：江客最晚，黄老爷子最早）。夜间村庄是"隙"态场景——起夜撞见事件的概率场就挂在熄灯序上。
- 赶集日的 NPC 移动本身就是叙事：谁推摊车、谁占老位置、谁今年没来（**缺席是最贵的文案位**，留空比写满有力）。

## 6. 称呼与关系里程碑

- 辈分称呼表（切片已锁机制的正式化）：初见称呼错误仅尴尬一句（无惩罚）；随好感解锁新称呼——**称呼变化=系统级里程碑**（"婶子"→"自家人"不进 UI，进台词：她第一次叫你"小X"而非"外来的"）。
- 命名规范：村人称谓用"排行+特征"（黄家大伯/磨坊婶/樟木祠那个药客），本名只在私事件与文书出现——**知道一个人的本名是关系进度**（年集供单上玩家名字由谁代写，即为此类节点）。

## 8. 恋爱候选 12 人（量产账内的写法纪律）

- 反"职业位轮盘"（星露谷被骂点：医生/矿工/巫师式功能人）。配方：**6 名五溪村满线候选全部从已有满线 NPC 出**（不新招 6 个"待定婚者"），6 名临水镇半线候选允许 3 个新面孔但每人必须先有"与婚恋无关的麻烦"。
- 候选彼此有边（候选×候选也是关系网，未选中的会在赶集日跟玩家聊起"你俩"——**三角压力用闲话池消化，不用失败系统**）。
- 一夫一妻（审核+叙事一致）；年龄带锁：候选全部 18–35；孩童/长辈不入池（小满 16 在切片只种弧不入池，量产期她的线写"长大"不写"被追"）。

## 9. 跨年增长（年尺度人物系统）

- 新年份"去年后果"落到人物：NPC 记住玩家（称呼/闲话引用/请托开口优先级随去年账变化）。
- 每人每年 1 个"不可逆小变化"预算（树裁了、窗换了、婚后的发型）——**不靠新地图靠旧人变**维持多年游玩的熟悉感。禁则：不整年零变化（违年感），不一年大改人设（违熟悉感）。

## 11. 检查清单（人物交稿必过）

- [ ] 不协调角落恰 1 且可画？欲望具体到物体？
- [ ] 删掉玩家，个人弧仍成立？
- [ ] 盲读 7/10 可辨？点缀词 ≤3 且不撞人？
- [ ] 关系边 ≥2 且注明方向/温度？有至少 1 条能进闲话池的边？
- [ ] 5 档日程齐？赶集日移动有戏？缺席位想过没有？
- [ ] 恋爱候选：先有自身麻烦，后是恋爱对象？
- [ ] 本年度"不可逆小变化"定了没？

## 12. 未决（随灰盒验证）

- 传话 60%/3 天的参数：切片先按显式话路手写 3 条，跑盲测看玩家是否自发利用。
- 面子的四种口吻是否够用（量产 18 人×4 态闲话文本量，超预算则合并"叹/啧"）。
- 江客母线与志怪正章的耦合深度（EA 前定稿，切片只埋"信"与"先到"两点）。
