# 桃花源（Tarcadia）竞品调研与可行性方案

> 版本 v0.1 · 2026-10-02 · 基于三路独立市场研究（中式田园竞品 / 全球 farm sim 品类 / 生产与商业可行性）汇总。文末附全部来源链接。

---

## 一、一句话定位

**"中式题材 + 星露谷式单机买断核心循环"目前市场上没有合格供给——这是桃花源的位置。**

不是"中国换皮的星露谷"，而是把中式田园的劳作内核（节气农事、饮食、赶集、宗族村落、志怪传说）做成有深度的模拟系统，以买断制单机 + 长线免费更新的品类正道发售。

## 二、市场结论（竞品调研摘要）

### 2.1 全球品类：需求被反复验证，盘子极大

| 事实 | 数据 |
|---|---|
| Stardew Valley 累计销量 | 2026 年突破 5000 万份，上线 10 年仍有月峰值 15.9 万 CCU |
| Cozy 标签新游供给 | 2015 年 2 款 → 2024 年 374 款/年（Steam） |
| Fields of Mistria | 5 人小队 3 年，EA 两年后 1.0 发售，好评率 97%，被 PC Gamer 称"星露谷后最强农场模拟" |
| Sakuna: Of Rice and Ruin | 日本稻作考据 150 万销量——**文化纵深是全球加分项，前提是劳作系统硬核** |
| Rune Factory: Azuma (2025) | 和风乡野卖点热销，东方美学全球可售再验证 |

### 2.2 中式赛道：两端拥挤，中间空白

- **手游端 F2P**（桃源深处有人家、江南百景图、这城有良田、淡墨水云乡）：有中式美术和种田皮，但被日课/体力/PVP/外观付费绑架，治愈基调随时被商业化撕裂。江南百景图证明**中式美术能引爆首发，内购循环撑不住长线**。
- **PC 端西式买断**（波西亚/沙石镇，帕斯亚）：证明中国团队具备做全球买断生活模拟的工业能力（波西亚 170 万份、约 3700 万美元收益），但从未用在国风题材上。
- **直接前驱**：《桃源村日志》（2026-01，48 元像素国风种田，首周约 3 万份，"特别好评"，被外媒称"中国版星露谷"）。**它验证了需求真实存在，但供给粗糙**：像素小品、文化符号浅尝辄止。留出约 12–18 个月窗口做高完成度升级版。

### 2.3 品类尸体的共性死因（必须避开）

1. **承诺与交付错位**（Coral Island：全价版缺承诺内容 → 差评雪崩，信誉不可逆）。
2. **体量不足**（Roots of Pacha：20–30 小时穷尽，低于品类 50h+ 预期即被弃）。
3. **只有皮肤没有循环**（"氛围种田"活不过促销季）。
4. **F2P 化**（Palia：上线前裁员 35%，本品类核心用户是单机买断党）。
5. **数值/日课撕裂治愈基调**（小森生活、米姆米姆哈——后者半年 iOS 仅 431 万元、已申请破产）。

## 三、产品方案

### 3.1 设计支柱

1. **节气历法为核心时钟**：24 节气驱动农事窗口（不是四季各 10 天的抽象季节，而是"清明前后种瓜点豆"的具象约束），叠加赶集日（逢五逢十）与经济脉冲。
2. **饮食系统为深度轴**：从田间到灶台的中式烹饪（食材×火候×药食同源），替代星露谷"料理=回能道具"的浅层设计。
3. **村落宗族社交网**：NPC 不是孤立的好感度条，而是辈分/姻亲/邻里关系图谱；红白喜事、祠堂、乡约是事件容器。婚恋保持一夫一妻（审核安全）。
4. **志怪为探索支线，包装为民间传说/梦境体系**（架空山海经），不写实呈现神鬼，规避"封建迷信"红线。
5. **反内购立场即营销**：无日课、无体力、无 PVP、买断含全部后续内容更新——直接对标手游种田玩家"被氪金毁了治愈"的流失人群，这是中式田园需求里已被验证（桃源深处口碑）、却没有产品承接的最大痛点。

### 3.2 美术与题材差异化

- 像素为主 + 水墨/工笔渲染的过场与 UI（《江南百景图》验证的出圈符号），避开"像素=简陋"标签，也避开 3D 成本。
- 情绪母题：归隐。"打工人返乡/穿越归隐"叙事在《桃源村日志》《桃源深处有人家》中均被验证有共鸣。

### 3.3 内容与商业标尺

| 项 | 底线 | 依据 |
|---|---|---|
| 首发主循环时长 | ≥40h，目标 60h+ | 低于 50h 区间被品类弃坑规律覆盖 |
| 可恋爱 NPC | ≥10 人，含完整个人线 | 品类基石 |
| 发布后更新 | 12–18 个月内一次免费大内容更新 | Stardew/Mistria 的信任货币 |
| 定价 | $24.99 / ¥68–78，1.0 不涨价 | Mistria 定价带 + 桃源村日志 48 元锚点 |
| 众筹 | **不做 Kickstarter 预承诺** | Coral Island 教训 |

## 四、生产方案

### 4.1 三档对比

| 维度 | A 单人全栈+外包 | **B 4–5 人小队（推荐）** | C 10 人+ |
|---|---|---|---|
| 周期 | 4–5 年 | 2.5–3.5 年（含 18–24 月 EA） | 2–3 年 |
| 成本 | $40k–80k | $150k–500k（国内约 ¥150–250 万） | $1M–2.5M |
| 内容量 | 20–40h，深度受限 | 50–80h，Mistria 级 | 80h+ |
| 回本概率 | 低（爆款运气） | **中：需 1.5–2 万愿望单** | 低：品类天花板撑不起 |

C 档在种田品类是财务自杀；A 档是五年人生豪赌；**B 档对标 Fields of Mistria，是唯一被近期验证可复制的路径**。

### 4.2 技术选型

- **引擎：Godot 4**。MIT 零成本零抽成，已占 Steam 新发售 8–10%，2D-first，移动移植路径通；2026-08 W4 Games 获腾讯领投 $1800 万，中国工具链支持向好。备选 MonoGame（若全员 C# 且要极致控制；星露谷本栈）。
- **AI 使用纪律**：AI 仅限内部提效（代码脚手架、概念探索、本地化初稿）；**最终像素美术与核心文案必须人做**——本品类卖温度，"AI slop"标签即口碑死亡（2026 数据：AI 参与新品占近 40%，畅销榜仅 11%）。发布时按 Steam 政策如实披露。

### 4.3 里程碑路线（B 档）

| 时间 | 节点 | 目标 |
|---|---|---|
| M0–M6 | 垂直切片 | 1 个村 + 节气农事 + 烹饪 + 3 个 NPC 线；核心循环 2h 好玩 |
| M6–M18 | EA 前量产 | 内容量 60%；Steam 页面 + 愿望单运营 |
| M18 | **Steam EA 发售** | 定价 $19.99；检验点：愿望单 ≥1.5 万 |
| M18–M30 | EA 迭代 + 2 次 Next Fest | demo→愿望单转化基准 19.3% |
| M30 | **1.0 全价发售**（$24.99 不涨价） | 主机/Switch 移植启动 |
| M30–M42 | 免费大更新 ×1 | 复刻 1.5 式信任红利 |
| M18+ | 并行申版号 | 6–12 月后补 WeGame/国区；移动端二期再议 |

渠道现实：无版号锁国区走 Steam 国际区（上架费 $100，满 $1200 可退，W-8BEN 预扣税 30%→10%）；主动开国区有法律风险，勿踩。

## 五、财务模型与风险

### 5.1 回收测算（保守）

- 愿望单价值口径约 $1–2/单；2 万愿望单 → 首年营收 $200k–600k。
- 回本线：B 档成本 ¥200 万 ≈ **$25 × 3.2 万份**。品类爆款（Stardew/Mistria）外，国产生活模拟买断的现实带是 3–15 万份（桃源村日志首周即 3 万）。
- **结论：能回本，但无安全垫。所有营销资源押在题材差异化一眼可辨（封面 3 秒传达"中式星露谷"）。**

### 5.2 风险登记

| 风险 | 等级 | 缓解 |
|---|---|---|
| 窗口期被抢（同类涌入） | 高 | 18 个月内 EA 可见；水墨美术+节气系统深度做不可快速换皮的壁垒 |
| Mistria 级完成度要求 vs 小队产能 | 高 | 砍轴不砍深：首发 4 轴（农事/烹饪/社交/志怪探索），砍钓鱼小游戏等杂物，后置 |
| 内容承诺管理 | 中 | 不众筹；EA 路线图只承诺已完成度 70% 以上的事 |
| 审核（志怪/民俗） | 中 | 架空山海经体系；无宗教符号、无冥婚类内容；一夫一妻 |
| 版号周期 | 中 | 国际区先行，国内渠道后置，不阻塞主线 |
| 单人/小队资金断裂 | 高 | 见 5.3 go/no-go 门 |

### 5.3 Go / No-Go 门

- **Gate 1（M6，垂直切片）**：核心循环盲测人均留存 >3h 且"再来一天"反馈出现，否则止损。
- **Gate 2（M18，EA 前）**：愿望单 <5000 则降级为 A 档节奏或转项目。
- **Gate 3（EA 后 6 月）**：销量 <8000 份则冻结 C 档扩张计划，走 3 年长尾。

## 六、总体结论

**有条件可行。** 品类需求全球最强、中式深度供给为零、《桃源村日志》刚完成低成本验证、窗口 12–18 个月。成立前提三条，缺一不建议启动：

1. B 档团队（4–5 人）且资金覆盖 ≥3 年；
2. 按 Mistria 完成度标准而非"氛围国风"立项；
3. 接受 EA 长线运营节奏（18–24 个月迭代换 1.0 爆发）。
