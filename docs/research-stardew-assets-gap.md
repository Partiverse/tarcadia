## 2. 切片窗内真缺口（需要动的五项）

- **A. 天气视觉层归口（本次对比新发现）**：presentation-ux §1 天气集五类齐全（绵雨/雷骤/连雨/雾/落雪），机制全锁、**视觉载体无人认领**——world-layers.md 全文零天气记账。切片 d3/d8/d13 绵雨是梦链载体，落雨体必须存在。建议：world 稿板补「天气层样张」小节（雨丝＝1px×3 斜线两帧墨点语法／雪＝物候冬板 z 勾 W 芯语法复用／雾＝n 半透明横带＋软边界），并把「天气层」记入 world-layers 欠账。半批工作量。
- **B. 厨房器物＋料理 UI**：切片 8 道配方（vertical-slice:92）需要灶/炒锅 sprite 与配方页版式——建议并入 UI 板 v0.4 候选（料理页＝安置/杂记同语法推演），器物 sprite 归 world 物件帧线。
- **C. 信纸阅读版式**：签条语法延伸，单件 48×64 级，M3。
- **D. 志怪半梦氛围件**：墨晕过场即旧忆载体，缺「隙态触发」视觉（雾层＋一帧异象）——极小，随志怪支线（§7）做。
- **E. Audio S7＋引擎 M0+M1**：均已挂账有主，非新缺口——询价发出＋Godot 安装两动作待行。

战斗与武器（vertical-slice:140）、钓鱼（同）、玩家畜牧（蛋＝NPC 供给正典）、家具/服装目录（无装饰经济线）、任务 HUD（presentation-ux §4.1 无 HUD 正典）、天气图标（§4.1 无天气 UI 正典——明日天气走世界三通道预告）、通用行走帧复用 SDV 制（tarcadia 独立三套已锁 art-style §4）。

## 4. SDV 做法的管线级采纳点（非资产，是方法）

1. **data-driven Content 清单**：SDV 全资产 JSON 化可热替换——tarcadia 迁移管线的 game/assets/MANIFEST.md＋M0+M1 转换器正走向同一形态，对齐即可，无需另做。
2. **季表整切**：SDV 换季＝整张 tilesheet 替换——tarcadia 键名同构色板管线是同目标的更优解（矩阵零改动），保持。
3. **NPC 日程驱动 sprite 复用**：SDV 用日程表决定现身与外观——tarcadia character-style §5 日程已锁，实现期对齐该法即可。
