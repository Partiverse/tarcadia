语义

语义色样张 · 朱砂人情／靛青知识

semantic ink · vermilion means someone seeks you

过场

水墨过场样张 · 墨晕聚拢／散开

ink-wash transitions · gather & scatter

过场卡是魂层最贵的资产：每局 ≤20 张（art-style §2「稀缺才有辨识度」）——本节只立画法不立片单。画法＝K/z/N 三阶墨晕＋留白过半＋竖排题字位（左侧固定留白列，题字 HTML 竖排叠加，示例「夜雨／天明」）；聚拢帧墨心浓、外晕散，散开帧碎点离析、K 只剩星点。过场是场景接管不是弹窗：无框、无按钮、无 Loading 腔。
