## 纪律（不可破）

- 美术宪法：16px 像素为体、水墨工笔为魂；朱砂只给人情事件；每角色 ≤12 色；禁 3D 预渲染；**禁 AI 成品像素入管线**（稿板全部精灵为代码内手排像素矩阵，即此纪律的自证）。
- 决议对齐 `docs/world-layers.md`（世界底图）与 `docs/narrative-mainline.md`（叙事脊柱）。
